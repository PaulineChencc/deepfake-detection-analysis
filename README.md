# Deepfake Detection Analysis

Analysis code accompanying a manuscript currently under review.

## Repository structure

- `analysis.py`: data processing and statistical analysis
- `data/`: input data directory; data are not included
- `output/`: analysis output directory
- `requirements.txt`: Python dependencies

## Run

```bash
python3 analysis.py
```

The script reads the three CSV files from `data/` and saves the results to `output/`.
